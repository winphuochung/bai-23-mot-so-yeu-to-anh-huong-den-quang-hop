# Web/app học tập — Khoa học tự nhiên 7, Bài 23

**Bài 23: Một số yếu tố ảnh hưởng đến quang hợp**
Môn Khoa học tự nhiên 7 — Chương trình GDPT 2018, sách Kết nối tri thức với cuộc sống.

Giáo viên: Lê Văn Thắng — Trường TH và THCS Phước Hưng, xã Nhơn Hội, tỉnh An Giang.

## Nội dung

Web/app học tập 6 phần: Khởi động, Khám phá, Mô phỏng, Sơ đồ tư duy, Luyện tập (10 câu trắc nghiệm tự chấm), Vận dụng.

Bốn yếu tố chủ yếu ảnh hưởng đến quang hợp: ánh sáng, nước, khí carbon dioxide và nhiệt độ (SGK tr. 104–107). Khám phá kèm đồ thị Hình 23.2 (nồng độ CO₂ — cây bí đỏ và cây đậu), Hình 23.3 (nhiệt độ — cây khoai tây, cây cà chua, cây dưa chuột) vẽ lại theo SGK và Bảng 23.1 tóm tắt.

Mô phỏng tương tác (hình SVG nội tuyến): kéo thanh trượt cường độ ánh sáng, lượng nước, nồng độ khí CO₂ và nhiệt độ để xem tốc độ quang hợp, bọt khí O₂, màu lá và trạng thái khí khổng thay đổi; 4 tình huống có sẵn: điều kiện thuận lợi, râm mát khô hạn, trưa nắng gắt 42 °C, CO₂ quá cao 0,20%.

## Cách dùng

- Mở file `index.html` bằng trình duyệt bất kì (không cần máy chủ).
- Học sinh đăng nhập bằng Họ tên + Lớp, học 6 phần, làm 10 câu trắc nghiệm rồi nộp bài.
- Điểm tự động lưu về Google Sheets của giáo viên (qua Apps Script Web App, chạy bằng tài khoản giáo viên).

## File trong repo

- `index.html` — web/app hoàn chỉnh, tự chứa (hình ảnh nhúng base64).
- `Web_Hoc_Tap_KHTN7_Bai23.md` — bản sao toàn bộ mã nguồn kèm khóa đáp án.
- `Code.gs` — Apps Script Web App ghi điểm vào Google Sheets (tab KetQua).
- `README.md` — file này.
- `assets-flow/` — 3 ảnh nền (đăng nhập, nền chính, hero) + logo giáo viên.
